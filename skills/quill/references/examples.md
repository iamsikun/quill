# Editing judgments

All examples below are constructed illustrations, not quotations or findings from
the user's manuscript. Use their reasoning, not their wording as a template.

| Source or issue | Useful revision or decision | Harmful change |
|---|---|---|
| “Selection-induced estimation bias constitutes an impediment to value assessment.” The supplied analysis explains selection on favorable errors. | “We may overestimate the selected treatment's value because treatments with favorable estimation errors are more likely to be selected.” The mechanism is explicit and source-supported. | Add this mechanism when the source does not establish it. |
| “The chosen action need not be optimal, and its value can still be overestimated.” | Keep selected and optimal distinct, even if “selected” repeats nearby. | Replace “chosen” with “best” for variety. |
| “Under Assumptions A–C, the estimator is consistent as the sample size grows.” | Preserve the assumptions and asymptotic scope while simplifying surrounding prose. | “The estimator is accurate in any sample.” |
| “Treatment and retention were positively associated in the observational sample.” | Keep the association, design, and population visible. | “Treatment increased retention.” |
| “Bias fell, but variance rose enough that mean squared error increased.” | Retain both components and the overall comparison. | “The method improved accuracy.” |
| “Rates were 3.0% and 2.4%; the first exceeded the second by 0.6 percentage points.” | If useful, explain that the relative increase is 25% using 2.4% as the denominator. | Call the difference a 0.6% relative increase. |
| “The diagnostic uses observed stability. We evaluate MAE using known simulation truth.” | Keep tuning inputs separate from evaluation quantities. | “Practitioners should choose the parameter minimizing MAE” when truth is unavailable. |
| “We randomly assigned 600 participants to one of three groups.” | Leave it unchanged if it fits the context. | “A randomized allocation procedure was implemented across a tripartite grouping.” |
| Methods say 0.4; the caption says 0.7 for the same parameter. | Flag the conflict and request the authoritative value. Preserve both until resolved. | Pick either value because it appears more plausible. |

## Basis and limits

The design follows the supplied reader-centered writing guidance: make claims,
reasoning, evidence, and conditions recoverable; distinguish meaning constraints
from stylistic preferences; and demonstrate restraint as well as transformation.
These illustrations are guidance, not evidence that the skill outperforms a strong
plain prompt. Evaluate new inputs separately from development examples.
