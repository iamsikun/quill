# Drafting from research materials

Determine the passage's job, audience, and available evidence. Use the supplied
notes, results, manuscript, and conversation before asking for additional context.
Do not require a venue, a fixed number of contributions, or a new workspace merely
to start writing. If an essential fact is missing, ask a focused question or state
the limitation while drafting supported material.

For a section or paper, form a compact argument outline: the question, contribution,
reasoning, evidence, and limits. Tie substantive claims to the actual provided
source. This may remain working context; do not create an administrative evidence
ledger for a small task. Preserve the difference between established findings,
interpretations, proposals, and open questions.

Write a coherent narrative rather than a tour of source files. Put information in
the order readers need it. State the contribution concretely without inflating
novelty. Adapt the organization to the work: theoretical, methodological, and
empirical papers need different exposition, and an existing manuscript may already
have a sound structure.

Use supplied, verified references for literature synthesis. Compare sources along
the dimensions relevant to the argument instead of summarizing one paper per
sentence. Do not invent a bibliographic record, claim a paper establishes something
without adequate source support, or turn drafting into an unrequested literature
search. Identify missing citation support separately.

Read the actual result sources before writing quantitative claims. Include the
metric, comparison, setting, uncertainty, and qualifications that determine their
meaning. Do not fill missing results with plausible values or convert an intended
experiment into a completed one. If the user wants an incomplete draft, mark any
placeholders explicitly so they cannot be mistaken for findings.

Deliver the requested prose after outlining. For a full manuscript, write the
supported sections and explain material omissions. Check terminology and claims
across the sections you changed. Preserve the user's file organization and output
format; use a managed Quill workspace only when it is already in use or requested.
